EJERCICIOS DE JAVASCRIPT

El HTML y el CSS ya están hechos. El trabajo es solo el archivo .js de cada
ejercicio (ahí dice "El código va aquí").

ARCHIVOS
  funciones.js ....... ejercicios 1 a 5 (se corren con Node o en la consola)
  dom/ ............... ejercicios 6 a 9 (se abre el .html y se escribe en su .js)
  guardar/ .......... ejercicios 10 a 12 (localStorage; se abre el .html)

CÓMO PROBARLOS
  - Los de dom/ y guardar/: se abre el archivo .html en el navegador con Live server, doble click o desde localhost:3000/public/practica-js/{nombre-carpeta}/{archivo}.html. El .js ya está enlazado. La consola (F12) muestra los errores.
  - funciones.js:  node funciones.js   (o se pega el código en la consola)

El enunciado completo de cada ejercicio está en la hoja de ejercicios.
