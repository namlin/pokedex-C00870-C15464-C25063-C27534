Ejercicios de JavaScript

Funciones por dentro

Funciones que devuelven funciones y que recuerdan datos (closures), y métodos de arreglos encadenados.

1

Contador con memoria

Fácil

La función crearContador() devuelve otra función. Cada vez que se llama a esa función devuelta, el número sube en uno: 1, 2, 3… Dos contadores distintos llevan su cuenta por separado.

Debe dar: const c = crearContador(); → c() da 1, c() da 2, c() da 3.

2

Saludo configurable

Fácil

La función crearSaludo(saludo) devuelve otra función. Esa función devuelta recibe un nombre y arma la frase completa.

Debe dar: const hola = crearSaludo('Hola'); → hola('Mari') → «Hola, Mari». Y crearSaludo('Adiós')('Mari') → «Adiós, Mari».

3

Lo caro del carrito

Medio

A partir de un arreglo de productos con nombre y precio, en una sola línea encadenada, se suma el precio solo de los que cuestan más de 1000.

Debe dar: con precios 500, 1200, 300 y 2000 → 3200.

4

Fábrica de descuentos

Medio

La función crearDescuento(porcentaje) devuelve otra función que aplica ese descuento a cualquier precio. A partir de ella se arman mitadDePrecio y diezPorciento.

Debe dar: const mitad = crearDescuento(50); → mitad(1000) → 500. crearDescuento(10)(200) → 180.

5

Agrupar por categoría

Difícil

A partir de un arreglo de productos con nombre y categoria, se devuelve un objeto donde cada categoría es una llave y su valor es el arreglo de nombres de esa categoría.

// de esto:
[{ nombre: 'Manzana', categoria: 'fruta' },
 { nombre: 'Pan',     categoria: 'panadería' },
 { nombre: 'Banano',  categoria: 'fruta' }]

// a esto:
{ fruta: ['Manzana', 'Banano'], panadería: ['Pan'] }

El DOM que escucha

Construir elementos desde datos y responder a lo que hace la persona.

6

Pintar una lista

Fácil

A partir de un <ul id="frutas"></ul> vacío y un arreglo ['Manzana', 'Banano', 'Uva'], se crea un <li> por cada fruta y se agregan a la lista.

Debe dar: tres <li> dentro del <ul>, uno por fruta.

7

Buscador en vivo

Medio

Con la lista del ejercicio 6 y un <input> de texto: mientras se escribe, se muestran solo las frutas que contienen lo escrito. Al borrar todo, vuelven a aparecer todas.

Debe dar: escribir «an» deja «Manzana» y «Banano»; borrar muestra las tres otra vez.

8

Botón que alterna

Medio

Un botón de «Me gusta» que, al tocarlo, cambia a «✓ Te gusta» y se marca; al tocarlo de nuevo, vuelve a «Me gusta». El estado se lleva en el atributo aria-pressed.

Debe dar: el texto y el aria-pressed (true/false) cambian en cada clic.

9

Leer un formulario

Medio

Un formulario con un campo nombre y un select de color. Al enviarlo, sin recargar la página, se muestra en pantalla «Hola NOMBRE, tu color es COLOR».

Recordar en el navegador

Guardar datos con localStorage para que sobrevivan a la recarga.

10

Guardar el nombre

Fácil

Un campo de texto y un botón «Guardar». Al guardar, el nombre queda en localStorage. Cuando se recarga la página, si ya hay un nombre guardado, aparece un saludo con él.

Debe dar: se guarda «Mari», se recarga, y sale «Hola de nuevo, Mari».

11

Favoritos que quedan

Medio

Una lista de colores, cada uno con un botón «♥». Al tocarlo, ese color se agrega o se quita de los favoritos, y la lista de favoritos se guarda para que siga ahí al recargar.

Debe dar: se marcan rojo y azul, se recarga, y siguen marcados.

12

El tema que elegiste

Medio

Un botón que cambia entre tema claro y oscuro (con un atributo data-theme en <html>). La elección se guarda para que, al volver a entrar, la página arranque con el tema elegido.
